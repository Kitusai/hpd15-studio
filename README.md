## Version Française

**HPD-15 Studio V2** est un bibliothécaire et éditeur moderne, open-source et universel conçu pour le Roland HandSonic HPD-15. Il vous permet de gérer vos kits, d'éditer les 18 zones en direct via MIDI/SysEx et de sauvegarder vos banques de sons au format `.json`.

Développé par [Kitusai](https://kitusai.com).

### 🚀 Téléchargement
Rendez-vous dans la section **[Releases](../../releases)** pour télécharger la dernière version universelle (`.dmg`) de l'application.

### 📋 Prérequis & Configuration Matérielle
* **Système :** macOS (Compatible nativement **Intel** et **Apple Silicon M1/M2/M3/M4** - Application Universelle).
* **Interface MIDI :** Interface USB-MIDI (Recommandée : **Roland UM-ONE**).
* ⚠️ **Attention (UM-ONE) :** Positionnez l'interrupteur physique de votre UM-ONE sur **TAB** (mode natif *Class-Compliant* sous macOS), et non sur *COMP*.

### 🛠️ Installation sur macOS
1. Téléchargez le fichier `.dmg` depuis les *Releases*.
2. Glissez l'application dans votre dossier **Applications**.
3. Au premier lancement (alerte de sécurité macOS) :
   * Faites un **clic droit** (ou *Control + clic*) sur l'application.
   * Sélectionnez **Ouvrir**, puis confirmez en cliquant de nouveau sur **Ouvrir**.

## English Version

**HPD-15 Studio V2** is a modern, open-source, and universal Librarian and Editor for the Roland HandSonic HPD-15. It allows you to manage your kits, edit all 18 zones in real-time via MIDI/SysEx, and save your custom sets as `.json` files.

Brought to you by [Kitusai](https://kitusai.com).

### 🚀 Download
Head over to the **[Releases](../../releases)** section to download the latest universal application package (`.dmg`).

### 📋 Requirements & Hardware Setup
* **OS:** macOS (Universal Binary natively supporting both **Intel** and **Apple Silicon M1/M2/M3/M4**).
* **MIDI Interface:** USB-MIDI interface (Recommended: **Roland UM-ONE**).
* ⚠️ **Important (UM-ONE):** Set the physical switch on your Roland UM-ONE to **TAB** (macOS native *Class-Compliant* mode), not *COMP*.

### 🛠️ macOS Installation Guide
1. Download the `.dmg` file from the *Releases*.
2. Drag and drop the app into your **Applications** folder.
3. On first launch (macOS security prompt):
   * **Right-click** (or *Control-click*) the app icon.
   * Click **Open**, then confirm by clicking **Open** again in the warning dialog.
