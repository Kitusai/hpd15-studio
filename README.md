# hpd15-studio
HPD-15 Studio is a modern, cross-platform (Universal macOS) Librarian and Editor for the Roland HandSonic HPD-15 percussion controller. Built with Electron, it features an interactive 18-zone SVG surface, robust MIDI/SysEx communication, real-time patch synchronization, and local JSON preset management. Developed by Kitusai (https://kitusai.com).
